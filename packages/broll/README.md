# `@narratage/broll`

Official B-roll authoring and lowering package. It owns B-roll items, local
entrance/exit motion, pair transitions, source audio and transition SFX. It
emits ordinary `VisualTrack` and `AudioTrack` values whose Presents participate
in Composition by their own absolute z.

The `<broll:Track>` Surface consumes explicit `CompleteSemanticMap`, authored Script selection,
source Blob and SVS Recipe edges. Each source is inspected and normalized through the shared media
Fragment; semantic-window placement and local motion are deterministic package Operations.

`BrollProgram@1` remains an executable vertical-slice fixture. The author-facing package is not
frozen until the old content-frame plus independent foreground/backdrop sampling witnesses lower
through the closed SVML Visual IR.

It does not generate media, select a Provider, read another Track, sample the
accumulated lower composite or implement Base/Screen FX.
