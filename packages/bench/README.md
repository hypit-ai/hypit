# `@hypit/bench`

Application-selected openers for independent Project Object work surfaces. A Bench declares the exact `@1` object
formats it can open and returns one disposable Web Surface session. It does not own the object, persist a route table,
choose a default Bench or know another Bench.

`@hypit/production-context` remains UI-free. Desktop, Codex or another Agent Host may combine explicitly selected
`hypit.project-bench` facets, list the Benches available for one `ProjectObjectRef`, and open any number of sessions.
Closing a session changes no project document. A fixed top bar, shared port and one-of-each document limit are not part
of this ABI.
