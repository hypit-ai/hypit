# `@hypit/caption-fine`

Fine flowing Caption for ordinary NLE projects.

Each materialized Cue is one normal Component Item containing complete display Words and exact
Item-local Unit time. Fine owns typography, outline and shadow paint, Cue and active-word boxes,
word-attribute faces, Cue entrance and current/trailing step or wipe Karaoke. Placement and lifetime
remain direct NLE Item facts.

This package is a critical migration of the old Fine Caption visual behavior, not its former authoring
architecture. It owns no Script declarations, semantic Timeline, tracking lookup, Recipe language,
Studio companion or upstream alignment. `@hypit/caption-nle` performs the common one-way
materialization; Fine contributes only its component symbol, persisted parameters and terminal
implementation.
