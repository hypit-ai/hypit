# `@hypit/raster-composition`

Ordered physical baking of raster Blobs into one PNG. Each layer carries a target-to-source
`SpatialMap`; array order is paint order. The package accumulates dynamically produced source Blobs
through pure Producers and emits a Need only when the completed layout is baked.

This is for materializing a model reference board or another deliberately flattened image. It is not
the editable visual composition used for a finished video: independently timed or adjustable Pictures
remain in the audiovisual Programme and are composed by its renderer.

There is no `Canvas`, `Frame` or `fit` vocabulary here. An author/compiler resolves those higher-level
choices into the shared spatial algebra before reaching this boundary. The package contains no Author
syntax, graph Fragment, Provider, model-reference semantics or NLE track concept. A creation tool may
invoke the same immediate Capability transiently after an Agent or author has selected the source
images; a deterministic downstream graph may consume it directly when those inputs are already fixed.
