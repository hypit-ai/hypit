# Reference relationships

Use a reference because the next image or Take needs a fact it already contains. The useful graph
follows creative dependencies: a person, a camera view, a shared place, a product or a physical state.
Reference count and graph depth are consequences of those needs, not production goals of their own.

## Keep the useful parent close

| Work | Useful relationship |
| --- | --- |
| UGC / Ranking | One character-and-scene image supplies all ordinary talking Takes. |
| Podcast | Main host view supplies the complementary host view; each host view plus product supplies its own product-holding variation. |
| Lifestyle montage | Each scene derives independently from the main character reference, with a logo/product added where needed. |
| Three-view interview | Shared two-person image supplies both close views; all Takes reuse that view set. |

A first useful camera image can establish person and location together. Another view can grow
directly from it when that parent already supplies the difficult facts. Describe what changes and
what matters to preserve.

Reference responsibilities can differ. A lifestyle image may preserve identity and physique while
changing clothes, camera and setting. A product-holding variation may preserve nearly the whole
camera view while changing hands and prop state. The same input does not imply the same preservation
rule. See [the worked image examples](examples/conversation-images.md).

For multiple references, connect actual image edges and explain their roles. “Reference 2” means the
second image in that request; reference numbers are request-local. A description of a reference cannot
supply a missing image.

## Let edited Takes meet through their shared world

In ordinary UGC, podcast and interview production, stable reference views support independently
generated Takes that meet at editorial cuts. Those cuts can remove dead pauses, change the object of
attention and make the performance feel like edited social video.

A truly continuous action is a different creative requirement. Direct that intended shot through
the chosen model's suitable mode; repeated references alone do not guarantee identical poses across
generated seams.

A Segment can carry multiple speakers and camera cuts. A split-screen Take can contain both the
speaker and a living silent listener. Neither a new Role turn nor another visible person mandates
another generated Take. Choose Segment boundaries for natural production passages and duration fit.

## Keep media provenance and visual role separate

A file may be an authored generated image imported after production elsewhere. Use it directly.
When future variation needs the original reference relationship, retain the useful prompt and source
images as project inputs rather than inventing them from the filename.

A-roll is the performance carrying the passage. It stays A-roll when covered by B-roll or presented
in an inset. Independently authored narration is also valid; it does not require an unseen talking
person to be generated. [Voice and performance](voice-and-performance.md) owns this distinction.

A short B-roll window may consume the beginning of a longer generated clip. A montage may combine
several scenes in one request. A still can be placed directly when a still is what the work needs.
Choose the shape through [B-roll craft](b-roll.md).
