# Terminal mix project components

This project-owned package contributes three NLE Components under one logical module:

- `manim-orbit` publishes a finite AVIR Picture Source, an opaque Manim Scene programme and its exact local
  Terminal execution facet;
- `blender-object` publishes another finite AVIR Picture Source, an opaque frame-independent Blender Python Scene
  programme and its exact range Terminal execution facet;
- `html-label` publishes a separate finite AVIR Picture Source and HTML implementation.

The Manim and Blender Scene source bytes are package resources. Their transparent WebMs are request-owned
`DerivedRenderProduct` values, not Media Assets or references persisted by the NLE.
