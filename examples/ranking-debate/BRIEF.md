# Brief

Create a complete 9:16 architecture-validation film in which two Chinese creator hosts debate which
AI-video capabilities deserve S tier. The result should feel like a lively social-video argument,
not a systems demo: four alternating speaking turns, a persistent ranking board, distinct speaker
Caption treatments, one hidden Cue, one one-off warning treatment, word-timed Karaoke and a final
verdict burst.

The production must prove the post-SVML seams:

- reusable AIGC work lives in Generation Graph files;
- accepted outputs become ordinary file-backed Media Assets;
- corrected TimedTranscript files are editable Media representations;
- one explicit project script aligns Script and evidence, then writes direct NLE facts;
- the finished NLE contains only Media Items, Component Items and exact values, with no live Script,
  Build, Product, Provider, semantic-name or reverse-lookup dependency.

The user explicitly authorized the paid generation described here through GPT Image 2 and Seedance 2
Mini, and invited ordinary token use. The covered first pass is two 2K portraits, four MiMo speech
outputs, four 720p Seedance speaking clips and their transcription. A materially expanded set of
requests remains a new production decision.
