# Asset provenance

The canonical Run generates five presenter clips with native narration from the current Author
Graph and consumes three external Manim renders. The inputs and source ownership are documented
below.

## Presenter and narration

- Presenter image reference: `assets/speaker-reference.jpg`
- Presenter picture and narration: the five `part-one.video` through `part-five.video` Outputs
  generated by `authors/main.svml`
- Seedance voice reference sample: `assets/edits/alex.wav`
- Generation authoring: `authors/main.svml` (the single active Author Graph)
- Presenter direction: `authors/direction.svml`
- The requested performance is an adult male speaking the authored English Script. Seedance uses the
  five-second sample for voice identity and generates the performance audio inside each video.

`assets/edits/english-seedance-person-full.mp4` is an earlier presenter export retained for
comparison. It is declared as `host-source` in `authors/assets.svml` but is not selected by the
active Film or canonical Run.

## Manim inputs

The following files are separate external renders produced from the project-local Python scenes.
They are declared as Author assets. For preparation and import, follow the
[external Manim handoff](README.md#external-manim-handoff).

| Active file | Authoring source | Role |
| --- | --- | --- |
| `manim-renders/math_block.mp4` | `manim-scenes/math_block.py` | Axes, growing parabola and moving tangent |
| `manim-renders/ml_block.mp4` | `manim-scenes/ml_block.py` | Three-layer network, signal propagation and falling loss curve |
| `manim-renders/physics_block.mp4` | `manim-scenes/physics_block.py` | Pendulum, force and velocity vectors with trail |

Each active Manim input is an opaque H.264 `yuv420p` MP4 at 1280x720 and 30 fps without audio;
`scripts/render-manim.sh` validates that media contract.

## Rebuild boundary

Follow the [project startup and handoff guide](README.md) for generated-file preparation. The
canonical `runs/render.svrun` has no machine-local Build records, so a fresh checkout generates the
presenter and downstream outputs from the current Author Graph.
