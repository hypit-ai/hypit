# Football ranking example

This complete example contains the reference project, three direct variants, and the additional
banana/reference-sync variants under their own directories. Each project directory includes its
SVML author source, SVS recipes/kits, and SVRun build or reuse sources.

Read the top-level `reference.svml`, `swap-host.svml`, `swap-effect.svml`, and `swap-topic.svml` with
their matching `.svrun` files first. The nested banana projects show explicit reuse and replacement
of generated media.
