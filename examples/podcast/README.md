# Podcast example

This complete example contains the reference project and three independent variants:
`reference.svml` / `reference.svrun`, `swap-host.svml` / `swap-host.svrun`,
`swap-item.svml` / `swap-item.svrun`, and `swap-app.svml` / `swap-app.svrun`.

Read each SVML source together with `recipes.svs` and the kit files under `kits/`; each SVRun keeps
the build target separate from authoring and recipe sources.
