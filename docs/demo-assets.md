# Demo assets

`docs/public/` is copied byte-for-byte into the documentation site. It is therefore distribution
content, not a test fixture, Build archive or ignored development output.

Only brand-neutral assets cleared for repository and website redistribution belong in this
directory. Generated Build outputs and example inputs belong under the ignored example
`assets/` / `output/` paths.

Every image, video, voice and likeness must have recorded provenance and redistribution permission.
Replacing an asset must update its source mapping under
`docs/.vitepress/theme/components/` and repeat that review.
