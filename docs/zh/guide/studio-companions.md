title: 组件的 Studio 控件
description: 为项目组件提供可识别的时间线 Item 和实用编辑控件。
---

组件可以把 Studio Companion 与绘制代码放在同一个包中。Companion 为组件提供可读名称和预览，指出作者可以选择的对象，并公开值得编辑的 Source 值。

## 选择可识别的对象

一个作者面对的事件或对象使用一个时间线 Item。一次揭晓可以先移动、再停留在榜单上，但仍是同一个 Item；一个协同场景需要整体编辑时，也可以保持为一个 Item。普通媒体 occurrence 已有合适的时间线 Item，无需额外描述。

为 Item 提供有意义的标签和能表达其含义的区间。入场区间可以早于画面消失时间结束，此时应把它标成入场，而不是当成对象的完整寿命。只有子事件确实需要单独选择时才增加子 lane。

## 公开有用选择

公开作者会有意修改的决定：文案、素材、位置、外观、时间和声音。实现细节留在组件内部。共享 Style 或 Frame 仍是一项共享决定，因此编辑它可能同时更新所有引用位置。

控件应匹配值的含义：

| 值 | 合适控件 |
| --- | --- |
| 短文案或长文案 | 单行或多行文本 |
| 数值大小 | 带有合适单位和范围的数字 |
| 两种状态 | 布尔开关 |
| 有限选项 | 带可读标签的选择器 |
| 精确颜色 | 可附建议色的颜色控件 |
| 有序或成组的值 | 列表或记录 |

当场景需要被识别、但没有适合直接修改的值时，只读标签与预览已经足够。不要仅仅因为代码里存在一个动画数值就把它公开成控件。

## 在真实编排中检查

在实际编排中打开组件。选择画面和时间线 Item，逐项修改公开值，确认 Source 与结果画面表达同一决定。组件含有移动和停留状态时，两者都要查看。共享值被修改后，也要查看其他本应共同变化的使用位置。
