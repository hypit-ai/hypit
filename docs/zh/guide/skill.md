title: 与 Agent 一起制作视频
description: 把参考视频或创作 Brief 交给 Agent，得到可继续编辑的视频作品。
---

把参考视频、创作 Brief，或两者一起交给 Agent。你可以提供人物照片、产品、Logo 或已有素材，并说明新视频要达到什么目标。Agent 理解这些材料，形成创意方案，再让画面、表演、图形、声音和剪辑共同服务于作品。

## 安装 Skill

```bash
npx skills add hypit-ai/hypit -g
```

Skill 提供制作知识，可执行的 `hypit` 包提供命令、组件、Runtime 和 Studio。Agent 可以找到已有的可执行安装，或准备选定的发行版本。Skill、可执行程序和视频项目各有自己的位置，也通过各自的安装渠道更新。

## 发展作品

理解参考片会在整片与细节之间往返：开头为什么抓人，表演怎样推进论述，画面、字幕、图形和声音各自发挥什么作用。带词时间的转写与帧序列帮助定位细节：什么出现了，如何运动，为什么在此刻重要。Agent 把整体理解与精确观察记入项目的参考笔记。

制作目标片会在意图与可见结果之间往返。换人物或产品，可能同时影响剧本、表演、场景和收尾，也会改变参考图片。Agent 围绕新的目标想清楚这些关系，在生成素材前，把视觉形象、参考关系、发音与表演方向写进图片 Prompt、Script 和视频 Prompt。等待生成时，可以同时制作组件与字幕。真实素材到位后，集中检查视觉层次、位置、出入场和时机是否承载了预期效果。

目标、私有事实、服务账户和花费由你决定。Agent 检查相关已有能力，在缺少某项能力时解释选择。例如，理解说话参考片可能需要准备本地 WhisperX 或选择托管转写；图片、视频生成可以通过支持的服务使用你自己的 Key，或使用 HypiHub 账户。

付费工作前，根据可用价格信息确认账户、制作范围与预算。Agent 在委托内承担日常创作与技术决定，说明理解与制作进展；范围或费用变化时再交给你决定。

## 保持项目可编辑

作品保存在普通项目文件里：

- 参考笔记解释原片的整体结构和可定位细节。
- Brief 与 Treatment 分别记录用户目标和 Agent 的创意方案。
- `.svml` 表达 Script、媒体、组件和合成；`.svs` 保存可复用的 Recipe。
- `.svrun` 选择 Author Source、已有 Output 和本次执行的目标。
- Build Result 留存实际产物与本次执行的事实。

项目组件是视频制作的一部分。它们与项目一起保存，可以表达新的视觉角色、Caption 样式族或图形行为。共享布局或动作的内容可以组织为同一场景，独立图形与字幕继续分开。说话视频用 Script 事件驱动这些关系，纯视觉动画则可以使用作者声明的时钟。需要跨项目共享时，可以通过所有者自己的 scope 发布普通的版本化包。

修改作品时，Run 可以复用已有 Result 中仍适用的 Output，也包括失败 Build 在失败前已经产出的可用素材。新的 Build 执行修改后的 Run。Studio 显示这份作品，并把支持的编辑写回 Source；Agent 对照目标审看实际成片。
