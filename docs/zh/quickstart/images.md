---
title: 图片准备
description: 区分模型参考素材与成片画面合成。
---

图片既可以作为独立的模型参考，也可以成为一张刻意烘焙的参考排版图。这些属于制作期素材准备，
不是 NLE Track。

## 含义独立时优先分别引用

模型能够接收多张参考图时，分别传入选定的人物、产品和场景图片，用顺序与 prompt 说明各自角色。
不要仅仅因为它们会被一起消费，就提前把它们压成一张图。

## 空间关系本身是证据时才烘焙

有时布局就是需要传给模型的方向：例如两个人必须分处上下半屏，或某个抠像角色必须出现在概念帧
的特定角落。制作工具可以通过 `@hypit/raster-composition`，将选定的 Raster 图片、`SpatialMap`、
透明度和绘制顺序烘焙成一张 PNG。

这张 PNG 是新的物理参考素材。该操作不携带人物、产品、prompt、模型、Timeline 或 Track 含义，
而且输入图层在下游不再可编辑。只有希望模型重新解释一张完整概念帧时才这样做。

如果成片必须严格保留分屏几何，或者叠加人物仍需独立调整，就保留各 Picture 或视频，在视听
Programme 中完成合成。

## 不在模型包里隐藏校正

生成包原样返回选定 Provider 的结果。GPT Image 或其他模型包不会暗中降噪、调色、裁剪或重新编码。
作品确实需要永久素材预处理时，由 Agent 显式完成，或由拥有该决定的项目组件实现。

## 移动人物抠像仍保持可编辑

人物需要出现在另一画面之上时，可将生成或已有视频交给
[`@hypit/volcengine-matting`](https://github.com/hypit-ai/hypit/blob/main/packages/volcengine-matting/README.md)。
得到的透明视频仍是普通 Media，应放进视听 Programme，让 Window、空间映射和绘制顺序继续可编辑。
