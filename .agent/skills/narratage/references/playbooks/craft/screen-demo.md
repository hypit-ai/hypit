# Screen-demo craft

- Decide whether the screen is the base subject or an overlay. A full-screen recording/screenshot is
  provided media; a floating card over live action is an overlay. Do not regenerate exact UI.
- Pair context and proof: show the person/device relationship, then show the actual UI from the user's
  position. Keep device orientation, screen content, and room geometry consistent.
- Keep UI text attached to the screen. Use Typography Track only for editorial callouts outside the
  UI. Use continuous motion when a document, receipt, or screen must remain unchanged.
- Ask for the real screenshot, recording, or alpha asset when fidelity matters. Mark the missing asset
  and gap instead of hallucinating a similar interface.
