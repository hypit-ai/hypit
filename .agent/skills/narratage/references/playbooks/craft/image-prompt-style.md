# Image prompt craft

Use English prompts for GPT Image and Seedance reference frames. Describe the final desired image,
not a list of edits to a source image.

## Four-part structure

1. **Reality contract:** realistic iPhone video-frame photograph; natural, non-glossy, clear
   background, realistic skin texture, natural light, no visual artifacts.
2. **Subject/story:** person, product, location, wardrobe, action, emotion, and physical objects.
3. **Camera/reference relationship:** shot size, camera ownership/placement, spatial direction, and
   explicit identity/product reference reuse.
4. **Texture close:** repeat a short reality contract if needed for a stable ending.

Do not put resolution, pixels, or aspect ratio in prose; use model parameters. Do not use conditional
language or mutually exclusive states; split different states into separate prompts. When using a
reference, state what it represents and what remains consistent. Use absolute spatial instructions
instead of “mirror”. The first identity anchor should show a clear complete face with both eyes visible.
