# Caption craft

- Use one Caption Program/Track for the program. Route speakers and styles through role/word rules,
  not duplicate caption tracks.
- Keep the spoken Script authoritative. Transcribe real audio; do not copy burned-in reference
  subtitles. Preserve original-language speech and translate separately when needed.
- Use the WhisperX SemanticMap for timing. A planner may group whole display Atoms but cannot rewrite
  text, invent timing, or split an indivisible Dual Text Atom.
- Keep captions in a safe region, avoid faces/product/UI, and use a stable-size Recipe when uniform
  readability matters. Hide words with an explicit visibility rule, not by deleting source text.
- If a format intentionally has no captions, omit caption components entirely.
